# Homebrew Tap for Buddhi Box

Private, offline speech dictation for Apple Silicon Macs.

## Install

```bash
brew install --cask pavan-gaikwad/tap/buddhi-box
```

## Upgrade

```bash
brew upgrade --cask pavan-gaikwad/tap/buddhi-box
```

## Uninstall

```bash
brew uninstall --cask buddhi-box
```

Learn more at https://buddhibox.app/
